## 全项目代码走读（熟悉架构）
- 架构核心：父窗口 React（App.jsx 2269 行，UI/状态/消息中转）↔ iframe（editorRuntime.js 2409 行，注入的纯脚本，直接操作真实 DOM），双向 postMessage。
- 关键链路：loadHtml → stripScripts 剥脚本 → rewriteAssets 资源转 blob（relMap 反查）→ 拼 STYLE_TAG+字幕数据+SCRIPT_TAG 注入 `</body>` → iframe srcdoc。
- 导出：exportClean 清编辑器足迹并重置首屏 active → 父端 restoreAndWrap 还原相对路径 + generatePlaybackScript 重生成播放脚本 → edited.html。
- 数据契约 `data-zt-*`：`data-zt-role="subtitle"` + start/end 相对秒数、`data-zt-id`、`data-zt-anim-effect/-duration/-delay/-return/-easing`、`data-zt-bound-to`（绑定写在字幕侧）、`focus-group`/`focus-item`。
- 注意坑：`selection` 消息不可清空 selectedSubIdx（否则解绑走错分支）；导出需重置 .slide active 否则首屏不显示；vite build 关了 emptyOutDir（避免批量删除触发安全确认）。
- 配套技能：`speech-visual-html/`（生成端 v5.4）、`vo-pipeline/`（edge-tts 口播产线 v1.0，实测通过）；`测试工程/speech-visual-test.html` 是 v5.3 契约回归夹具。
